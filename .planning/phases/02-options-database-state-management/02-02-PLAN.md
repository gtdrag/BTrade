```python
from enum import Enum
from dataclasses import dataclass
from typing import Optional

class WheelState(Enum):
    CASH = "CASH"
    SHORT_PUT = "SHORT_PUT"
    HOLDING_SHARES = "HOLDING_SHARES"
    COVERED_CALL = "COVERED_CALL"

VALID_TRANSITIONS = {
    WheelState.CASH: {WheelState.SHORT_PUT},
    WheelState.SHORT_PUT: {WheelState.CASH, WheelState.HOLDING_SHARES},
    WheelState.HOLDING_SHARES: {WheelState.COVERED_CALL},
    WheelState.COVERED_CALL: {WheelState.HOLDING_SHARES, WheelState.CASH},
}

def transition(current: WheelState, next_state: WheelState) -> WheelState:
    """Validate and return next state. Raises ValueError on invalid transition."""

@dataclass
class WheelCycle:
    id: int
    state: WheelState
    underlying: str
    put_strike: Optional[float]
    put_premium_received: float  # default 0.0
    put_expiry_date: Optional[str]
    shares_held: int  # default 0
    cost_basis: float  # default 0.0
    covered_call_premiums_collected: float  # default 0.0
    realized_pnl: Optional[float]
    opened_at: str
    closed_at: Optional[str]
    created_at: str
    updated_at: str

@dataclass
class OptionsPosition:
    id: int
    cycle_id: int
    symbol: str
    option_type: str  # "PUT" or "CALL"
    strike: float
    expiry_date: str
    dte_at_entry: int
    quantity: int  # default 1
    premium_received: float
    delta: Optional[float]
    gamma: Optional[float]
    theta: Optional[float]
    vega: Optional[float]
    iv: Optional[float]
    status: str  # "OPEN" or "CLOSED", default "OPEN"
    close_premium: Optional[float]
    opened_at: str
    closed_at: Optional[str]
    created_at: str
    updated_at: str
```

    ```python
    # ==================== Wheel Strategy Operations ====================
    ```

    1. create_wheel_cycle() -> int:
       - Check no active cycle exists (SELECT WHERE closed_at IS NULL AND state != 'CASH' — or more simply: WHERE closed_at IS NULL). If one exists with state != CASH, raise ValueError("Active cycle already exists").
       - Actually, allow creation when no non-closed cycle exists. The check: if there's a cycle with closed_at IS NULL, raise ValueError.
       - INSERT into wheel_cycles with state='CASH', underlying='IBIT', opened_at=get_et_now().isoformat()
       - Return lastrowid

    2. get_active_cycle() -> Optional[Dict[str, Any]]:
       - SELECT * FROM wheel_cycles WHERE closed_at IS NULL ORDER BY id DESC LIMIT 1
       - Return dict(row) if row else None

    3. get_cycle_history(limit: int = 50) -> List[Dict[str, Any]]:
       - SELECT * FROM wheel_cycles ORDER BY id DESC LIMIT ?
       - Return [dict(row) for row in cursor.fetchall()]

    4. transition_wheel_state(cycle_id: int, next_state: WheelState, reason: str, **updates) -> None:
       - Get active cycle, verify cycle_id matches
       - Call validate_transition(WheelState(cycle["state"]), next_state) — raises ValueError if invalid
       - Build SET clause: state=next_state.value, updated_at=now, plus any **updates
       - If next_state == WheelState.CASH and "closed_at" not in updates: set closed_at=now
       - UPDATE wheel_cycles
       - Call self.log_event("INFO", "wheel_transition", details={"cycle_id": cycle_id, "from_state": current.value, "to_state": next_state.value, "reason": reason})

    5. open_wheel_position(cycle_id: int, symbol: str, option_type: str, strike: float, expiry_date: str, dte_at_entry: int, premium_received: float, quantity: int = 1, delta: float = None, gamma: float = None, theta: float = None, vega: float = None, iv: float = None) -> int:
       - Validate option_type in ("PUT", "CALL"), raise ValueError if not
       - Validate cycle_id exists in wheel_cycles (SELECT id FROM wheel_cycles WHERE id = ?), raise ValueError if not found
       - INSERT into options_positions with all fields, status='OPEN', opened_at/created_at/updated_at = get_et_now().isoformat()
       - Return lastrowid

    6. close_wheel_position(position_id: int, close_premium: float) -> None:
       - UPDATE options_positions SET status='CLOSED', close_premium=?, closed_at=now, updated_at=now WHERE id=?
       - Never DELETE — per locked decision

    7. get_cycle_positions(cycle_id: int) -> List[Dict[str, Any]]:
       - SELECT * FROM options_positions WHERE cycle_id = ? ORDER BY id ASC
       - Return [dict(row) for row in cursor.fetchall()]

    8. compute_cycle_pnl(cycle: Dict[str, Any], current_price: float = 0.0) -> Dict[str, float]:
       - This is a STATIC/standalone method (not touching DB). Takes cycle dict as returned by get_active_cycle().
       - If cycle["state"] == "HOLDING_SHARES" or cycle["state"] == "COVERED_CALL":
           unrealized = (current_price - cycle["cost_basis"]) * cycle.get("shares_held", 100)
       - Else: unrealized = 0.0
       - realized = cycle.get("realized_pnl") or 0.0
       - Return {"unrealized_pnl": unrealized, "realized_pnl": realized}
       - NOTE: P&L is computed on read, NOT stored — per locked CONTEXT.md decision

    - When transitioning to record covered call premium: caller passes **updates with cost_basis=new_value, covered_call_premiums_collected=new_value.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering | transition_wheel_state state bypass | mitigate | All state changes route through transition_wheel_state() which calls validate_transition(). Direct SQL UPDATE of state column is never used. Tests verify invalid transitions raise ValueError. |
| T-02-06 | Tampering | SQL injection via **updates kwargs | mitigate | Only dict keys are used in f-string SQL (field names), values go through parameterized queries (?). Keys are controlled by caller code (not user input). Phase 2 has no external input surface. |
| T-02-07 | Tampering | Invalid option_type insertion | mitigate | open_wheel_position() validates option_type in ("PUT", "CALL") before INSERT. Raises ValueError on any other value. |
| T-02-08 | Denial of Service | Multiple active cycles | mitigate | create_wheel_cycle() checks for existing cycle with closed_at IS NULL before INSERT. Raises ValueError if one exists. Single-cycle invariant maintained. |
| T-02-09 | Tampering | Cost basis sign error | mitigate | Tests explicitly verify direction: $48 strike - $2.50 premium = $45.50 basis. Covered call $1.50 reduces to $44.00. Wrong direction would fail tests. |
| T-02-10 | Information Disclosure | Cycle data in log_event | accept | Transition logs contain cycle_id, from/to state, and reason. No PII. Financial data is the user's own. Low risk. |
