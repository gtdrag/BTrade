| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | get_ibit_options_chain response logging | mitigate | Do not log raw API responses containing account data; log only contract count and any errors. Follow existing pattern where `_request()` handles response without logging full body. |

| T-01-03 | Denial of Service | Malformed API response crashes parser | mitigate | Use `.get()` with default values for all response field access. Skip contracts with missing expiry fields. Handle both list and single-dict response shapes. |
| T-01-04 | Spoofing | Mock client used in production | accept | `create_etrade_client(dry_run=True)` returns mock — controlled by config, not external input. Same risk surface as existing equity mock. |
