**1. Add `detect_and_process_expiry()` method to WheelStrategy in `src/wheel_strategy.py`:**

```python
def detect_and_process_expiry(self) -> Optional[str]:
    """Check if the active put has expired or been assigned.

    Returns:
        "assigned" if assignment detected,
        "expired_otm" if put expired worthless,
        None if no action needed (no cycle, wrong state, not expired yet).
    """
```

Implementation:
1. Get active cycle: `cycle = self.db.get_active_cycle()`. If None, return None.
2. Check state: if `cycle["state"] != "SHORT_PUT"`, return None. (Idempotency: already HOLDING_SHARES or CASH means prior run handled it.)
3. Get open positions: `positions = self.db.get_cycle_positions(cycle["id"])`. Filter to `status == "OPEN"`. If none, return None.
4. Get the put position: `put_pos = open_positions[0]` (one put per cycle in Phase 3).
5. Check expiry: `from datetime import date; expiry = date.fromisoformat(put_pos["expiry_date"]); today = get_et_now().date()`. If `today <= expiry`, return None (not expired yet).
6. Check live E*TRADE options positions: `live_options = self.client.get_options_positions(self.account_id_key)`. Get set of live option symbols: `live_symbols = {p["symbol"] for p in live_options}`.
7. If `put_pos["symbol"]` is still in live_symbols, the put is still open (hasn't settled yet) — return None.
8. Put is gone from live positions. Now determine: assignment or OTM expiry.
9. Check for IBIT shares in equity positions: `equity_positions = self.client.get_account_positions(self.account_id_key)`. Look for IBIT in equity positions: `ibit_shares = [p for p in equity_positions if p.get("Product", {}).get("symbol") == "IBIT" and p.get("Product", {}).get("securityType") == "EQ"]`.
10. **If IBIT shares found (assignment):**
    - Calculate cost_basis: `cost_basis = cycle["put_strike"] - cycle["put_premium_received"]`
    - Transition: `self.db.transition_wheel_state(cycle["id"], WheelState.HOLDING_SHARES, "put_assigned", shares_held=100, cost_basis=cost_basis)`
    - Close position: `self.db.close_wheel_position(put_pos["id"], close_premium=0.0)`
    - Log event: `self.db.log_event("INFO", "put_assigned", {"cycle_id": cycle["id"], "strike": cycle["put_strike"], "cost_basis": cost_basis})`
    - Return "assigned"
11. **If no IBIT shares (OTM expiry):**
    - Calculate realized P&L: `realized_pnl = cycle["put_premium_received"] * 100` (full premium kept, 1 contract = 100 shares)
    - Transition: `self.db.transition_wheel_state(cycle["id"], WheelState.CASH, "put_expired_otm", realized_pnl=realized_pnl)`
    - Close position: `self.db.close_wheel_position(put_pos["id"], close_premium=0.0)`
    - Log event: `self.db.log_event("INFO", "put_expired_otm", {"cycle_id": cycle["id"], "realized_pnl": realized_pnl})`
    - Return "expired_otm"

**2. Add `_job_assignment_detection()` method to SmartScheduler in `src/smart_scheduler.py`:**

```python
def _job_assignment_detection(self) -> None:
    """Check for put assignment or OTM expiry."""
    now = get_et_now()
    if not is_trading_day(now.date()):
        logger.info("Not a trading day, skipping assignment detection")
        return

    if not self.wheel_strategy:
        logger.warning("WheelStrategy not initialized, skipping assignment detection")
        return

    try:
        result = self.wheel_strategy.detect_and_process_expiry()

        if result is None:
            logger.info("Assignment detection: no action needed")
            return

        if result == "assigned":
            cycle = self.wheel_strategy.db.get_active_cycle()
            cost_basis = cycle["cost_basis"] if cycle else 0.0
            strike = cycle["put_strike"] if cycle else 0.0
            message = (
                "📋 *PUT ASSIGNMENT DETECTED*\n\n"
                f"• Shares acquired: 100 IBIT\n"
                f"• Strike: ${strike:.2f}\n"
                f"• Cost basis: ${cost_basis:.2f}\n\n"
                "Next: Covered call suggestion coming (Phase 4)."
            )
            self._send_notification(message)
            self.db.log_event("INFO", "assignment_notified", {"cost_basis": cost_basis})

        elif result == "expired_otm":
            cycle = self.wheel_strategy.db.get_active_cycle()
            # After OTM expiry, cycle is closed (CASH state) — get from history
            from .database import get_database
            db = get_database()
            history = db.get_cycle_history(limit=1)
            last_cycle = history[0] if history else {}
            pnl = last_cycle.get("realized_pnl", 0.0)
            message = (
                "✅ *PUT EXPIRED WORTHLESS (OTM)*\n\n"
                f"• Full premium kept\n"
                f"• Realized P&L: ${pnl:.2f}\n\n"
                "Cycle complete. Ready for next put signal."
            )
            self._send_notification(message)
            self.db.log_event("INFO", "otm_expiry_notified", {"realized_pnl": pnl})

    except Exception as e:
        logger.error(f"Assignment detection failed: {e}", exc_info=True)
        self.db.log_event("ERROR", "assignment_detection_error", {"error": str(e)})
        self._send_notification(f"⚠️ Assignment detection error: {e}")
```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11 | Tampering | False assignment detection | mitigate | Require BOTH conditions: put gone from options positions AND IBIT shares present in equity positions. Neither alone is sufficient. |
| T-03-12 | Tampering | State double-transition | mitigate | Check `cycle["state"] == "SHORT_PUT"` before acting — if already HOLDING_SHARES or CASH, skip (idempotency). `transition_wheel_state()` also enforces valid transitions. |
| T-03-13 | Denial of Service | E*TRADE API failure during detection | mitigate | Wrap all API calls in try/except. On failure, log and notify — do NOT modify cycle state. Detection will retry next day. |
| T-03-14 | Repudiation | Assignment without audit trail | mitigate | `db.log_event()` records every detection outcome ("put_assigned", "put_expired_otm") with cycle_id and financial details |
| T-03-15 | Information Disclosure | Cost basis in notification | accept | Cost basis is sent to the authorized Telegram user only (protected by `_is_authorized()` on the bot). This is the intended recipient. |
