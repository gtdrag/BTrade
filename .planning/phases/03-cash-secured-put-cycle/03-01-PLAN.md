**WheelStrategy class:**
```python
class WheelStrategy:
    def __init__(self, client, db: Database, account_id_key: str = "default"):
        self.client = client  # ETradeClient or MockETradeClient
        self.db = db
        self.account_id_key = account_id_key
        self.pullback_threshold = -2.0  # IBIT must drop >= 2% from 5-day high
        self.delta_min = 0.20
        self.delta_max = 0.30
```

**`get_put_signal(self) -> Optional[PutSignal]` method:**
1. Check active cycle state: `cycle = self.db.get_active_cycle()`. If cycle exists and `cycle["state"]` is `"SHORT_PUT"` or `"HOLDING_SHARES"`, return None (prevents stacking).
2. Get IBIT 5-day high using yfinance: `yf.Ticker("IBIT").history(period="5d")["High"].max()`. If history is empty, log warning and return None.
3. Get current IBIT price using yfinance: use the last Close from the same history call, or `yf.Ticker("IBIT").info.get("regularMarketPrice")`. Actually, for simplicity and to avoid a second API call, use `history["Close"].iloc[-1]` as current price proxy.
4. Calculate pullback_pct: `(current_price - five_day_high) / five_day_high * 100`. If `pullback_pct > self.pullback_threshold` (i.e., not enough pullback), return None.
5. Call `self.select_put_strike()` to get the best contract. If None, return None.
6. Validate cash: `cash = self.client.get_cash_available(self.account_id_key)`. If `cash < contract["strike"] * 100`, log reason and return None.
7. Return PutSignal populated from the selected contract and pullback data.

**`select_put_strike(self) -> Optional[Dict]` method:**
1. Fetch chain: `chain = self.client.get_ibit_options_chain()`
2. Filter to puts: `[c for c in chain if c["option_type"] == "PUT"]`
3. Filter to delta range: `[c for c in puts if self.delta_min <= abs(c["delta"]) <= self.delta_max]`
4. If empty, return None
5. Return `max(target_puts, key=lambda c: c["bid"])` — highest premium in range

Import `yfinance as yf` at the top. Import `Database` from `src.database`, `WheelState` from `src.wheel_state`. Use `logging.getLogger(__name__)` for logger. Use `get_et_now()` from `src.utils` for any timestamps.

Run tests until all 12+ pass.
