# Requirements Archive: BTrade Wheel Strategy v1.0

**Defined:** 2026-03-18
**Completed:** 2026-04-09
**Core Value:** Systematically generate income from IBIT options by running the wheel strategy with disciplined entry signals and semi-automated execution

## v1.0 Requirements — All Complete

### E*TRADE Options API

- [x] **API-01**: Bot can fetch IBIT options chains with Greeks (delta, gamma, theta, vega, IV) from E*TRADE
- [x] **API-02**: Bot can preview and place options orders (sell-to-open puts, sell-to-open calls, buy-to-close) via E*TRADE
- [x] **API-03**: Bot can query options positions from E*TRADE portfolio API
- [x] **API-04**: Bot validates quote freshness (<60s) before using options prices for orders

### Database & State

- [x] **DB-01**: Options positions are persisted with contract details, Greeks at entry, premium, and status
- [x] **DB-02**: Wheel cycles are tracked with state machine (CASH -> SHORT_PUT -> HOLDING_SHARES -> COVERED_CALL)
- [x] **DB-03**: Assigned shares are recorded with adjusted cost basis (strike price minus premium received)
- [x] **DB-04**: Cost basis is updated when additional premiums are collected (covered call premium reduces basis)

### Cash-Secured Puts

- [x] **CSP-01**: Bot identifies favorable put entry conditions (IBIT pullback >= 2% from 5-day high)
- [x] **CSP-02**: Bot selects put strike using delta targeting (0.20-0.30 delta)
- [x] **CSP-03**: Bot selects expiration in 30-45 DTE range
- [x] **CSP-04**: Bot sends Telegram message with suggested put trade for user approval
- [x] **CSP-05**: User can approve, adjust, or reject suggested put trade via Telegram
- [x] **CSP-06**: Bot validates sufficient cash to secure the put before suggesting trade

### Assignment Detection

- [x] **ASGN-01**: Bot detects option assignment by comparing E*TRADE positions to database state daily (8:30 AM ET)
- [x] **ASGN-02**: Bot sends Telegram notification when assignment is detected with details
- [x] **ASGN-03**: Bot automatically suggests covered call parameters after assignment detection

### Covered Calls

- [x] **CC-01**: Bot selects call strike using delta targeting (0.25-0.35 delta) at or above adjusted cost basis
- [x] **CC-02**: Bot sends Telegram message with suggested covered call for user approval
- [x] **CC-03**: Bot validates call strike is at or above adjusted cost basis
- [x] **CC-04**: When shares are called away, bot updates wheel cycle state back to CASH and records full-cycle P&L

### Profit Management

- [x] **PM-01**: Bot monitors open options positions every 30 minutes during market hours
- [x] **PM-02**: Bot suggests closing position at 50% profit via Telegram (buy-to-close)
- [x] **PM-03**: Bot suggests defensive roll when position is tested with credit-only validation
- [x] **PM-04**: Bot monitors expiration approach and sends alerts at 21 DTE
- [x] **PM-05**: Rolling is limited to max 2 rolls per position, credit-only

### Transition

- [x] **TR-01**: Bot has wheel_mode_enabled flag that disables intraday strategies when active
- [x] **TR-02**: Telegram command /wheel shows current wheel cycle status
- [x] **TR-03**: Telegram command /wheelmode to enable/disable wheel mode
- [x] **TR-04**: Streamlit dashboard displays options positions, wheel cycle state, and premium collected
- [x] **TR-05**: Bot sends daily position summary at 4:30 PM ET
