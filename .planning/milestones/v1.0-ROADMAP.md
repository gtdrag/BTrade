## Milestone Summary

**Key Decisions:**
- Replace intraday with wheel: Wheel generates consistent income vs directional bets
- IBIT only (not leveraged ETFs): More liquid options, standard margin, no leverage decay
- Semi-automated via Telegram: Maintain human oversight for options trades
- 30-45 DTE default: Best theta decay curve, well-studied timeframe
- Signal-based put entry: Avoid selling puts at unfavorable times; wait for pullbacks

**Key Accomplishments:**
1. Full E*TRADE options API integration with chain fetching, order placement, and position querying
2. Wheel cycle state machine (CASH -> SHORT_PUT -> HOLDING_SHARES -> COVERED_CALL -> CASH) with cost basis tracking
3. Signal-based cash-secured put selling with Telegram approval flow (Approve/Adjust/Reject)
4. Covered call suggestions with cost basis protection (hard filter prevents selling below breakeven)
5. Profit management with 50% profit-taking, defensive rolling (credit-only, 2-roll limit), and 21 DTE alerts
6. Wheel mode toggle that cleanly gates all intraday strategies, with Telegram commands and Streamlit dashboard

**Issues Resolved:**
- BTC/roll order argument signatures fixed during milestone audit (wrong positional args for E*TRADE API)
- Delta sign handling (put deltas are negative from E*TRADE)
- Separate approval events for each flow type (prevents race conditions)

**Technical Debt:**
- `compute_cycle_pnl()` DB method orphaned (dashboard reads realized_pnl directly)
- Human verification items deferred: BTC end-to-end, roll guards, DTE idempotency, Streamlit visual rendering
- REQUIREMENTS.md traceability table checkboxes not auto-updated
